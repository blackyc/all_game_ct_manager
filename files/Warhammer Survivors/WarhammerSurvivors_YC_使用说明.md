# Warhammer Survivors (战锤:幸存者) · 使用说明

**版本 v1.0.12**　作者 YC

## 使用

1. 先启动游戏（进主菜单即可，部分功能需进一局战斗）
2. 双击 `WarhammerSurvivors_YC_Trainer.exe`，自动连接
3. 底栏绿点 + 显示进程号 = 连上；未连接会提示「重新连接」
4. 开关类：点整行或左侧黄色开关切换
5. 数字类：填好数值点右侧「应用」，滑块拖到位置即时生效
6. 先点「一键停止全部」（1.5 秒后按钮恢复）再关窗口，已改内容自动还原

## 功能（22 项）

| 组 | 功能 |
|---|---|
| 生存 | 无限生命 · 无敌 · 无冷却 |
| 资源 | 金币（直接改数值）· 金币 +1000 |
| 倍率 | 金币倍率 1~10 · 经验倍率 2~20（滑块，整数） |
| 战斗 | 力量/伤害 · 攻击范围 · 攻击装填 · 幸运/几率 |
| 生存属性 | 最大生命 · 防御/护甲 · 移动速度 · 拾取范围 |
| 全属性 | 全属性锁定（滑块 0~10 统一应用） |
| 解锁 | 一键解锁配件箱/角色/颜料罐（含武器/关卡/皮肤/秘法/成就/秘闻） |
| 速度/弹道 | 游戏速度 · 玩家速度 · 敌人速度 · 弹道个数 |

## 使用提示

- **属性类**（力量/范围/装填/生命等）：写入真实属性表后游戏重算会覆盖，
  修改器每 80ms 自动补写，无需等升级。
- **攻击装填**建议 0.3 ~ 1；填太大（如 99）攻击间隔会变得极长，看起来像不打。
  想连发直接点「无冷却」（内部留 10% 余量，不会卡死）。
- **弹道个数**要先打开它自己的开关。
- **一键解锁**：开完后关闭再打开角色 / 配件箱 / 颜料罐界面才看得到
  （锁定状态是界面创建时缓存的）。两个剧情模式（40K / 帝皇时间）都会解锁，
  切换模式后等 2 秒会自动补写到新存档。
- **金币**跟随当前剧情模式的存档，切换模式后读写都会落在当前模式。

## 注意

- 单文件版首次启动要解压约 30MB，**慢 3~5 秒属正常**
- 同一时间只允许开一个修改器
- 部分杀软可能误报，加白名单后重试
- 游戏以管理员身份运行时，修改器也要右键以管理员身份运行
- 仅用于单人离线
