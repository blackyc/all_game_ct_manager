# VED 制作笔记

适用：VED 0.0.1865（buildID 1880 / client_version 0.0.1865_7e178fd）。Unity Mono。

## 一、技术路线

- 全部 **AOB 特征码 + 代码注入**，不含硬编码地址 → 同版本换电脑通用，小更新只要特征码还在就能用；
- 启动脚本注册两个符号：`pPlayerController`（玩家）、`pEnemyController`（敌人）；
- 取消勾选会还原原始字节，可逆；运行时不依赖 Mono/IL2CPP 功能。

## 二、玩家对象偏移（pPlayerController）

| 偏移 | 类型 | 含义 |
|---|---|---|
| `+1D8` | int | 最大能量 |
| `+1CC` | float | 当前 HP |
| `+1D0` | float | 最大 HP |
| `+50` | float | 动作速度（倍率，改大 = 加速） |
| `+1A4` | byte | 自动弹反（1 = 开启并冻结） |
| `+C8` | byte | 冲刺/弹反连按无延迟（1 = 开启并冻结该值） |

## 三、敌人对象偏移（pEnemyController）

| 偏移 | 类型 | 含义 |
|---|---|---|
| `+114` | float | 最大 HP |
| `+11C` | int | 当前护盾（一次只影响一个敌人） |
| `+B0` | float | 攻击间隔 |
| `+C0` | float | 攻击计时 |
| `+48` | float | 动作速度（0 = 完全静止） |

## 四、玩法级开关

| 符号 | 类型 | 作用 |
|---|---|---|
| `blockOn` | byte | 无限格挡（每帧强制格挡，无冷却空窗） |
| `animSpeedMul` | float | 动作速度倍率（默认 1.0，1.5/2.0 常用） |
| `enemyFreeze` | byte | 敌人定身（动画归零 + 停止移动 + 不可攻击） |
| `enemyAnimSpeed` | float | 敌人动作速度（0 静止 / 0.3 慢动作 / 1.0 正常） |

## 五、经验

- **速度类**改 float 倍率最省事、立刻生效；被每帧重算的值必须在注入点锁，别只写字段。
- **商店无限刷新**改的是"刷新冷却"，不是硬造物品，稳定得多。
- 代码级补丁（无限格挡/敌人定身）比改字段稳，字段常被打回。
- 同一数值常有多份副本，先确认"写哪个能让界面变"。
- 地址每次开游戏都不同属正常（AOB 会在启动时重新定位），不需要手改。
