# VED ( ved ) · 使用说明

**版本 v1.0.2**　作者 YC

## 使用

1. 先启动游戏并进入存档
2. 双击 `VED_YC_Trainer.exe`，自动连接
3. 底栏绿点 + 显示进程号 = 连上；还在标题界面会提示「等待进入存档」，读档后自动生效
4. 开关类：点整行即可切换，金色为开
5. 数字类：填好数值点右侧「应用」
6. 先用「一键停止全部」再关窗口，代码类功能会自动还原

## 功能（12 项）

| 组 | 功能 |
|---|---|
| 战斗 | 自动格挡 · 敌人定身 · 一击必杀 · 一击破甲 · 100% 暴击 · 动作速度 |
| 生存 | 生命锁定 · 能量锁定 |
| 资源 | 猫猫代币（可改数值 / +1000） |
| 奖杯 | 铜奖杯 · 银奖杯 · 金奖杯 |
| 解锁 | 全角色解锁 · 解锁所有战斗手册 |

## 使用提示

- **敌人定身 / 一击必杀 / 一击破甲**：作用于「当前锁定的那个敌人」，切换目标会跟过去，需进战斗后再开。
- **全角色解锁**：角色界面只在打开时读一次，开关后要**重开角色选择**才看得到。正常推图时建议关掉（开着时新角色不会写进存档），只在挑人时临时开。
- **解锁所有战斗手册**：改的是「是否已见」判定，不动存档；关掉即恢复原样。**故意没动击杀记录**，不会影响商店品质与解锁进度。
- **猫猫代币 / 奖杯**：直接写存档数值，改完立刻生效。

## 注意

- 单文件版首次启动要解压约 30MB，**慢 3~5 秒属正常**
- 同一时间只允许开一个修改器（重复开会提示）
- 部分杀软可能误报，加白名单后重试；启动失败会弹窗说明
- **不需要管理员权限**；若游戏以管理员启动，修改器也要右键以管理员身份运行
- 仅用于单人离线
