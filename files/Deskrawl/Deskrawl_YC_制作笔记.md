# Deskrawl（挂机破坏神）制作笔记

适用 Deskrawl.exe 1.0.2a。加密相关见同目录 `ACTk_解密笔记.md`（完整破解过程）。

## 一、技术路线

- 关键字段被 **ACTk 2.x 加密**，不能直读直写；启动脚本先破解算法并注册符号，之后条目一律走符号；
- 「解析存档」补齐只在存档里的值（经验/天赋点）：首次约 15 秒，之后瞬时；
- 属性/战斗类开关是"改写加密字段"，填 0 或取消勾选即还原。

## 二、实时数据

| 符号 | 类型 | 含义 |
|---|---|---|
| `FXD_HP` / `FXD_MANA` | int | 当前生命 / 法力 |
| `FXD_LEVEL` | int | 等级 |
| `FXD_XP` | int | 当前经验（需解析存档） |
| `FXD_MAXHP` / `FXD_MAXMANA` | int | 最大生命 / 法力（基础值；面板上限 = 基础 + 装备） |
| `FXD_DMG` | int | 基础伤害（未计装备） |
| `FXD_PSTAT` | float | 主属性（智力/力量） |
| `FXD_TALENT` | int | 可用天赋点（需解析存档） |

## 三、修改与开关

| 符号 | 类型 | 说明 |
|---|---|---|
| `FXD_MSSET` / `FXD_ASSET` | float | 移速 / 攻速设定值（0 = 不修改） |
| `FXD_MSSHOW` / `FXD_ASSHOW` | float | 当前移速 / 攻速（只读） |
| `FXD_GOD` / `FXD_MPI` / `FXD_KILL` / `FXD_NOCD` | byte | 锁血 / MP 无限 / 一击必杀 / 无 CD（1 = 开） |
| `FXD_MPSET` | int | MP 设定值（默认 100，0 = 自动棘轮） |
| `FXD_SAVESCAN` / `FXD_SAVERES` | byte | 触发解析存档 / 解析状态（0 未解析 1 进行 2 成功 3 失败） |

## 四、金币模块（需先勾金币模块）

| 符号 | 类型 | 说明 |
|---|---|---|
| `FXDG_GOLD` | int | 当前金币 |
| `FXDG_SET` | int | 金币锁定值（默认 999999，0 = 不锁） |
| `FXDG_ADDR` | 8 字节 | 钱包地址（自动定位失败时手填） |

## 五、经验

- 加密字段**不要直接改数值**，会被解密回原值；必须"破解算法 + 按加密格式写回"（金币就是紧凑版 ObscuredInt：`hidden@X, key@X+4`）。
- 锁血/一击必杀属于战斗结算，找结算函数比追字段稳。
- 移速/攻速会被持续重算，需要按帧锁。
- 存档类数值（经验/天赋点）只在存档里，必须解析存档。
- 内存里**不存在**独立的"最大生命"字段，面板值是基础值 + 装备加成算出来的。
