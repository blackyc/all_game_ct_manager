# Frontier Tale (开拓物语) · 使用说明

**版本 v1.1.6**　作者 YC　（适配 Build.26751033 / Steam）

## 使用

1. 先启动游戏并读档进世界（还没进存档时定位不到数据，所有数值类功能不可用）
2. 双击 `FrontierTale_YC_Trainer.exe`
3. 首次连接需要 **约 10 秒**（全内存扫描定位存档对象），期间不要重复点「重新连接」；
   底栏显示进程号 + 金币数字 = 已连上
4. 游戏重启后 trainer 会**自动重连**（状态栏显示"检测到游戏重启，自动重连中…"），
   等 3~5 秒即可，不用手动操作
5. 开关类：点整行或左侧黄色开关切换
6. 数字类：填好数值点右侧「应用」
7. 「一键停止全部」：还原全部属性加成、关闭补丁、解除数量锁定

## 使用提示

- **无敌**：只影响主角，村民/敌人不受影响；受击动作照常播放
- **武器无耐久**：耐久数字不再下降，不会碎
- **瞬间搜刮**：野外背包的搜索进度条瞬间完成
- **金币 / 背包上限 / 负重上限 / 背包格数加成 / 角色属性**：写的是会话内存，
  **读档或重启后游戏会按存档重算**，重新「应用」一次即可
- **背包格数加成**：总格数 = 基础 50 + 填的值。改完要在**仓库↔背包之间搬一次东西**，
  游戏才会重建背包列表，然后重开背包界面查看
- **数量拉满 999**：可堆叠物品（装备除外）全部改成 999 并持续保持，
  要等下一次**自动存档**落盘后重启游戏才固化；「一键停止全部」解除保持
- **角色属性填的是"加成值"**：面板显示 = 基础值 + 这里填的数（填 100 = 面板加 100）
- **堆叠上限 9999** 不单独显示开关：点「数量拉满」时会自动启用，保证 999 不被游戏按堆叠上限裁剪

## 附带 `FrontierTale_YC.CT`（Cheat Engine 表，8 条目）

- `[★0] 构建校验`：先勾，锚点字节对不上会弹窗提示（换游戏版本需重新取偏移）
- `[1]~[4]`：无敌 / 武器无耐久 / 瞬间搜刮 / 堆叠上限 9999
- `[5] 数量拉满`、`[6] 金币 → 99999`：一键执行
- `[7] 饱食度不降`：0.5 秒锁定满值
