# ForgeTax 制作笔记

Unity Mono。版本见 CT（v3.1.1 / v3.2.0 各一份，注意区分游戏版本）。

## 一、核心思路

敲击结果是枚举：**0 破坏 / 1 损坏 / 2 维持 / 3 成功 / 4 大成功**。
游戏先按概率掷点写入"本次结果"，再由结果推导剑的价值、等级、损坏状态。
所以在结果写入后改这一字节即可强制大成功，**不需要动概率**。

## 二、符号与偏移

| 符号 | 类型 | 含义 |
|---|---|---|
| `fxo_ctl+5` | byte | 强制大成功开关（1 = 开） |
| `fxo_ctl+6` | byte | 强制结果值（1 损坏 / 2 维持 / 3 成功 / 4 大成功） |
| `fxo_ctl+7` | byte | 同步界面概率显示（1 = 开） |
| `fxo_value` | double | 当前剑价值 |
| `fxo_grade` | int | 剑等级 |
| `fxo_strikes` | int | 敲击次数 |
| `fxo_outcome` | int | 上次结果（0~4） |
| `fxo_broken` | byte | 是否已损坏（1 = 是） |
| `fxo_display+144/148/14C/150/154` | int | 界面概率千分比：破坏/损坏/维持/成功/大成功（合计 1000） |
| `fxo_room+2B0` | double | 本期订单额 |
| `fxo_room+2B8` | double | 已完成交付 |

## 三、经验

- **判定点比显示值重要**：界面概率是派生显示，改它不改变结果。
- 结果枚举定位技巧：变化前后差值扫描 + 过滤 0~4。
- 价值是 double，别用 float 扫；等级/次数是 int。
- 强制结果后，价值/等级/损坏状态由结果推导，**不要再硬改**，否则与逻辑打架。
- 关闭方式：把 `fxo_ctl+5` 改回 0，或取消勾选 → 自动还原原始字节。
