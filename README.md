## 使用

**CT**：Cheat Engine 7.5+ → `Open Process` 附加游戏 → `File → Load` 载入 → 勾选条目

**Trainer(exe)**：双击运行，自动连接游戏；游戏以管理员身份运行时，exe 也需右键以管理员身份运行
