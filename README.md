## 四、通用使用方法

1. 启动游戏,进入存档
2. 打开 **Cheat Engine 7.5 或更新版本** → `Open Process` → 附加到游戏进程
3. `File → Load` 载入对应目录下的 `.CT` 文件
4. **勾选需要的脚本条目** —— 脚本会自动在游戏模块里搜索特征码、分配内存、注册符号
5. 数值类条目双击即可修改(可勾选左侧方框冻结)
6. **取消勾选脚本条目会自动还原原始字节与数值**,不留残留

## 五、设计原则(为什么这些 CT 换电脑也能用)

| 原则 | 说明 |
|---|---|
| **AOB 特征码定位** | 不写死地址,按字节模式在 `GameAssembly.dll` 等模块里查找目标位置 |
| **运行时动态分配** | 变量与符号由脚本在目标进程里 `alloc`,每台电脑自动分配,无需适配 |
| **无 Mono/IL2CPP 依赖** | 运行时不调用 mono 接口,只要 CE ≥ 7.5 即可 |
| **可逆** | `[DISABLE]` 段会还原代码字节;涉及数据状态的(如敌人定身)会额外做数据还原 |
| **失败安全** | 特征码找不到时脚本会报错退出,不会误改其它代码 |
