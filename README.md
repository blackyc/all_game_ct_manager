## 使用

**CT**：Cheat Engine 7.5+ → `Open Process` 附加游戏 → `File → Load` 载入 → 勾选条目

**Trainer(exe)**：直接双击运行，检测到游戏进程后自动连接，若游戏以管理员身份运行，exe 也需要右键「以管理员身份运行」。

## 注意

- 数值会写进角色存档，改动前请先备份；仅用于单人离线。
- 修改器需要与游戏版本匹配；游戏大更新后偏移可能失效，等表格更新。
- 血源 v1.7.0：**开着「不死模式」不要跳崖/掉出地图**——不死会让你活着掉下去，游戏去加载缺失的坠落兜底场景会崩溃（`guest+0xdab420`）。要跳崖请先关掉不死，关掉后会正常死亡且不崩溃。
- 血源 v1.7.0：无限体力依赖「血量驱动 + `0x3C`」定位，驱动失效时会自动重新定位（5 秒冷却），换图后若体力短时间仍消耗属正常，稍等即恢复。
- 血源 v1.7.5：「**补满强化材料**」会把血石碎片/双子/血石块/血岩各补到 99。**这是写进存档的改动**（重启游戏仍在，无法回退），使用前请先备份存档；只在单人离线用。
- 血源 v1.7.5：若窗口提示「**已找到游戏，但打不开进程**」，说明游戏以管理员身份启动，请**右键以管理员身份运行**修改器。
- 血源 v1.7.5：窗口那行小字（`HP 793/793  弹 20  瓶 20  回响 xxx`）是自检信息。若某项显示 `--` 或空着，说明没定位到，请截图反馈。
