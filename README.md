## 使用

Cheat Engine 7.5+ → `Open Process` 附加游戏 → `File → Load` 载入 CT → 勾选条目

> **ForgeTax**:需 CE 7.5+ 并启用 Mono(菜单 `Mono → Activate Mono Features`)。
> 载入后**先勾选 `[★0] 启动/重新定位`**(不勾的话条目会是空的),再勾选 `[★1] 强制大成功`
> → 之后每次敲击固定为「大成功」,剑永远不会被损坏;想固定别的结果改 `[★2]`(1损坏 / 2维持 / 3成功 / 4大成功)。
> 关闭:取消勾选 `[★0]`,或把 `[★1]` 改回 `0` → 自动写回原始字节。
> 地址运行时自动定位,不改存档、不联网、不启动外部程序。
> 重开游戏 / 重开 CE 后:重新附加进程 → 重新载入 CT → 再勾一次 `[★0]`。

> 仅供单机 / 离线游戏学习研究使用,请勿用于联机游戏。
